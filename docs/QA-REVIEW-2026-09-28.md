The new released-file fixture was saved with the retained 0.4.2 extension. It has
custom style and scene settings but no annotation objects. Its first annotation
creation advances schema steps 6 through 15 once, preserves the custom values, and
does not turn the new annotation into a legacy style override. A fresh scene stamps
current before creation. Migration and normal anchor property updates now avoid
writing linked and overridden objects or their meshes. A local annotation can be
created in a scene containing linked Dimensions collections, and drawing enumerates
both the local and linked collections.

The modal suite audits every operator with `modal()` for explicit `cancel()` and
exception cleanup. Representative tests exercise exact invoking-viewport cleanup,
idempotent external cancellation, editor change, injected exception, partial
guide-plane repair, undo/redo, and file load. Existing lifecycle coverage exercises
save/reload, append/link, library override, scene copy/move, and two scenes.

The repository's one open GitHub report, issue #2 (new Edit Mode vertices after
Extrude, Inset, or Poke), matches the corrected live-BMesh anchor validation in
this candidate. A regression creates a vertex in Edit Mode and binds it without a
mode switch. The GitHub issue remains open until this candidate is delivered.

SVG and PDF serialize the same page strokes. Page/orientation and furniture cases
verify the selected annotation rectangle stays inside margins and outside the title
block. Fit Scale and export use those identical bounds; minimum title-block fields
fit an ISO date and the supported scale value; overflowing metadata is refused.
Printable ASCII and named technical glyphs have native strokes, and ink bounds
match left, center, and right alignment.

## Installed UI and usability

The validated ZIP was installed and enabled through Blender's extension CLI in an
isolated 5.2.2 profile, then opened on a 1600 × 900 virtual display. The Dimensions
sidebar drew normally at its default narrow width with a live 2.828 m annotation
and a long name in the manager. The manager's selected value, state, Select, Frame,
Hide, Rename, and Delete controls remained readable. A prior two-column bulk-style
row truncated **Apply Named Style**; the rebuilt ZIP was installed again and the
full-width **Apply Named Style**, **Reset to Global Style**, and **Delete Scope**
labels were visually verified. The creation controls still show their full names.

The vector sheet's former icon-only Fit Scale and date actions now carry text labels.
The sidebar remains dense: eleven icon-only snap toggles require tooltips, and the
Output panel sits below several management panels. A focused discovery/usability
study should decide whether those controls need grouping or a separate surface;
there was no incorrect action in the tested creation and manager workflows.

## Performance

On Blender 5.2.2 Linux, the final `draw_benchmark.py` run measured 0.518 ms per
rebuilding frame for 10 dimensions with 10 cubes and 0.498 ms with 10,000 cubes.
The 500-dimension case measured 29.099 ms rebuilding (34 fps) and 5.110 ms cached.
It meets the documented 30 fps budget but has a narrow worst-case margin. The
`snap_benchmark.py` 1M-vertex case measured 60.707 ms cold build, 0.118 ms
reprojection, and 0.019 ms steady query, inside the 100 / 50 / 8 ms budgets. The
100-annotation export remains far below its 5-second test budget. No performance
work is justified by a breached budget in this review; keep the 500-dimension
rebuild case in the release gate.

## Product recommendations

- Do not promise authoritative live Area or face-guide measurements after a
  topology-changing modifier unless Blender supplies unique, stable face identity.
  The existing base-mesh/captured workflow and explicit Fallback state are more
  trustworthy than guessed correspondence.
- Do not add arbitrary Chain member permutation as a UI capability. Adjacent
  members share a geometric joint; moving an item in a list has no unambiguous
  dimension meaning and previously produced invalid backward segments. Keep the
  current actionable refusal and support insertion, deletion, and anchor repair.
- Keep the fixed single-sheet title block deliberately bounded. It works for one
  physical page, but a full CAD document/template system would require a separate
  layout model and user study rather than more fields in this sidebar.

All accepted hardening tickets now pass on the tested Linux Blender versions. A
1.0 compatibility promise still calls for supported-platform release QA and a
deliberate schema freeze; no Blender 6.0 stable release was available for this pass.
